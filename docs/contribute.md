# How to Contribute?

Anyone can contribute to this site by sharing ideas, creating content, and more. To contribute, a basic level of technical knowledge is required to configure the application, write content, and verify the changes in local computer before push.

Please checkout project description page for setting up local development environment.

Please create a [**ticket**](https://github.com/nemo97/Janar-Icche-Jiggasha/issues) in the project section on GitHub. In the future, we plan to create a video tutorial demonstrating how to set up the application and contribute effectively.
